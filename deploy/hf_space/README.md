# AI Crossover Point — hosted demo

This Space runs in **replay mode**: there is no GPU here, so live generation
is switched off. Everything else is live and interactive:

- **Home** — headline results
- **Live demo → ⏯ Replay** — a real recorded generation (1.40× speedup, output identical)
- **How it works** — animated round-by-round walkthrough + crossover explorer
- **Results** — every measurement, read from the result files

To run live generation (needs an NVIDIA GPU with ~6 GB VRAM), clone the
GitHub repository and follow `REPRODUCE.md`.
